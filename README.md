# Capstone-Project-UPI-Transaction-Data-Analysis

## 📌 Project Overview
This business intelligence and data analytics project evaluates transaction performance, fraud patterns, and customer behavior across a UPI (Unified Payments Interface) platform. Analyzing **100K transactions** totaling **$4.24M**, the project identifies core operational inefficiencies, high-risk segments, and platform growth opportunities. 

The end-to-end workflow spans data engineering, statistical hypothesis testing in Python, and interactive dashboard development in Power BI to deliver actionable strategic recommendations.

---

## 🚀 Key Business Metrics
* **Total Transactions Analyzed:** 100,000
* **Total Transaction Value:** $4.24M
* **Platform Success Rate:** 92.14%
* **Technical/User Failure Rate:** 5.87%
* **Overall Fraud Rate:** ~2%
  
---

## 🛠️ Tech Stack & Tools
* **Microsoft excel:** used for initial data exploration and quick analysis
* **Data Manipulation & EDA:** Python (`pandas`, `NumPy`)
* **Statistical Analysis:** `statsmodels`, `scipy`
* **Data Visualization (Exploratory):** `matplotlib`, `seaborn`
* **BI Dashboarding & Data Modeling:** Power BI (DAX)
* **Database Architecture:** Database Relationship Mapping (ERP/ERD)
